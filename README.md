# 📊 Sales Dashboard — Excel

## 📌 Project Overview

This project is an interactive **Sales Dashboard developed using Microsoft Excel** to analyze sales performance across managers, states, brands, and customer sectors.

The workbook uses a transaction-level dataset along with **PivotTable-based analysis** to transform raw sales data into business-focused summaries and dashboard visualizations.

The project demonstrates how Excel can be used for practical **sales analytics, performance monitoring, and business reporting**.

---

# 🎯 Business Objective

The objective of this project is to analyze sales performance and identify important patterns across different business dimensions.

The dashboard helps answer questions such as:

* What is the overall sales value?
* Which manager generates the highest sales?
* Which state contributes the most sales?
* Which brand has the highest sales value?
* Which customer sector contributes the most sales?
* How is sales distributed across customer sectors?
* How does sales performance vary across managers and geographical regions?

# 📊 1. Dashboard

The **Dashboard** sheet provides a visual representation of the sales analysis.

The dashboard is supported by multiple PivotTable summaries covering:

* Manager performance
* State performance
* Brand performance
* Customer sector performance
* Sector contribution percentage

The dashboard converts these summaries into an easier-to-understand management view.

---

# 🗃️ 2. Data

The `Data` sheet contains the underlying transaction-level sales dataset.

The dataset contains **1,000 sales records** and includes the following fields:

| Field           | Description                    |
| --------------- | ------------------------------ |
| Date            | Sales transaction date         |
| Year            | Transaction year               |
| Month           | Transaction month              |
| State           | Sales state                    |
| Manager         | Responsible sales manager      |
| Brand           | Product brand                  |
| Customer Sector | Customer business sector       |
| Sales Value     | Value of the sales transaction |
